# Real-Time Collaborative Workspace & Analytics Engine

## 🚀 How to Run locally with Docker
1. Clone the repository: `git clone <your-github-url>`
2. Boot PostgreSQL: `docker compose up -d`
3. Launch FastAPI: `fastapi dev main.py`
4. Open UI: `http://localhost:8000` | Open API Docs: `http://localhost:8000/docs`
